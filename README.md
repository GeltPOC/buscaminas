# Buscaminas

Juego de Buscaminas completo construido con Next.js, TypeScript y Tailwind CSS.

## Características
- Tablero configurable (fácil, medio, difícil o personalizado)
- Revelar celdas con clic izquierdo
- Colocar/quitar banderas con clic derecho
- Expansión automática de celdas vacías
- Contador de minas restantes
- Temporizador de partida
- Detección de victoria y derrota
- Reinicio de partida

## Iniciar

```bash
npm install
npm run dev
```
